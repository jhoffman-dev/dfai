Signing in on the web

DFAI in a browser — on an iPad, say — opens your vault by signing in with GitHub. What it does once you are in is in DFAI on the web and iPad.

Sign in

  1. Once, first: install the DFAI GitHub App on your vault. On the app's GitHub page press Install, choose Only select repositories and pick your vault's repository alone. It asks to read and write that repository's files and nothing else: not your other repositories, not your profile, not your email.
  2. Open DFAI's web address and press Sign in with GitHub, then Authorize on GitHub.
  3. GitHub sends you back and DFAI opens. On later visits you are let straight in.

What stays where

  • No server keeps your notes. A small sign-in service swaps GitHub's one-time code for a key and hands it to the page; it never sees a note and stores nothing.
  • The key lives in the page's memory and lasts a few hours; DFAI renews it before it runs out. What renews it is kept by the browser where the page's own code cannot read it.

Sign out

  • Press Sign out at the bottom-left corner. DFAI forgets this browser, cancels its key at GitHub, and signs out its other tabs too.
  • To cut DFAI off everywhere, on GitHub go to Settings → Applications → Installed GitHub Apps and remove DFAI, or narrow it to fewer repositories. The web build then signs you out with “GitHub no longer lets DFAI reach your vault”, and signing in again reconnects it.
  • If DFAI says it could not reach its sign-in service while you were signing out, sign out again once you are online, or this browser may let you back in on its next visit.
