Notes

A note is a markdown file. Its name is the title you type at the top of the page.

Make one

  • ⌘N makes a note in the folder you're looking at, or at the top level. Made while you're looking at an archived note, it goes at the top level, not in the Archive.
  • Right-click a folder in Pages → New note here.
  • On a type's page, New <type> (New person, New book) — on the toolbar or at the foot of the table — makes a note of that type from its template, in the type's home folder.
  • ⇧⌘N (or ⌥⌘N) opens quick capture: type a line and it becomes a task in the Inbox, without leaving the page — see Quick capture.

Write

Type markdown as you go (# for headings, - for lists, [] for a checkbox) or type / for the block menu: headings, lists, task list, quote, code block, callout, table, divider, Link to note, Image and Query (a live query).

A link to a note can sit on its own line as a card with the note's picture and summary — see Bookmarks.

A code block is coloured by the language named after its fence, like ```python: Bash (sh), CSS, JSON, Markdown, Python, Rust, SQL, TypeScript and JavaScript (ts, js), HTML and XML, and YAML (yml). The colours arrive a moment after the note opens, the first time each language is shown; the code doesn't move when they do. A block with no language, or one not on the list, stays plain.

# with a space after it is a heading; # straight followed by a word is a tag, like #idea — see Tags. @ and a name links a person — see People and mentions.

Move and arrange blocks

Rest the pointer on a paragraph, heading, quote, table, highlight or any other block and a ⋮⋮ handle appears in the margin to its left. Each item of a list has its own. It goes away as soon as you type, and comes back when you move the mouse.

  • Drag the handle to move the block; a line shows where it will land. Hold ⌥ as you drop to copy it instead. You can drag a block into or out of a list or a quote. A block only lands where the note's file can hold it: a table cell is one line of text, so only a paragraph can be dropped into one — anything else is refused and nothing moves — and a highlight always lands between the note's blocks, never inside a list or a quote. A numbered item dragged out of its list stays numbered.
  • Click the handle for the block's menu: Add block above, Add block below, Duplicate, Move up, Move down and Delete. The arrow keys move through it and Esc closes it.
  • From the keyboard, with the caret in a block: ⌘/ opens its menu, ⌥↩ adds a block below and ⌥⇧↩ one above, ⌘D duplicates, ⇧⌘↑ / ⇧⌘↓ move it, and ⇧⌘⌫ deletes it. ⇧⌘↑ and ⇧⌘↓ are the Mac's own keys for selecting to the start or end of the text; here they move the block instead, as in Notion, and only on the first or last block, where there is nowhere to move, do they select as they do everywhere else.
  • Each of these is one ⌘Z, and what you type afterwards is another: after Add block below and some typing, one ⌘Z takes back the typing and a second takes back the block. Moving a block up and then down puts the note back exactly as it was.
  • Two lists that come to stand next to each other — because you moved or deleted the block between them — stay two lists: the second is saved with a different bullet (* instead of -, or 1) instead of 1.), which is the only way markdown keeps them apart. Only those marker characters change; the rest of the list is left byte for byte as you wrote it, and any ^id stays on its own list.
  • A copy is never a second highlight. Duplicating a highlight, or dragging a copy of it, gives a plain quote of its words and comment. A block's ^id stays with the original only, so links to it keep pointing to the same place. A moved highlight is still the same highlight.
  • Deleting a highlight — from its menu, with ⇧⌘⌫, or with ⌫ or Delete while it is selected — removes it from the book's note, the way the reader's highlights panel does. A Kindle highlight leaves a hidden marker behind so the next sync does not bring it back. This is a change to the note's file, so ⌘Z does not bring it back.

Properties

Properties sit under the title as rows: a status pill, dates like Tue, Sep 22, 2026, numbers, links to other notes.

  • + Add a property asks for a name and a kind (text, number, date, checkbox, select, multi-select, URL, relation, thumbnail). On a typed note choose Add to <Type> to add it to every note of that type, or Only this note.
  • A multi-select is one line, with commas between the items: Quill, Fenn. One that holds a comma of its own is in double quotes — "Payroll, Larkspur", Quill — so editing the others never cuts it in two; type one the same way. It saves as you type, as a list in the file, except while a quote is open: it waits for the closing quote, and Esc or leaving the field with one still open puts back the list as it was. An item you leave alone is kept exactly as the file has it — a number stays a number, and one holding a line break (shown with a space in its place) keeps it. An empty item is dropped.
  • Relations show the linked notes as chips; click one to open it, × to remove it. A relation that allows many keeps an Add… button.
  • A relation suggests notes as you type — you don't have to remember what a note is called or how it's written. Click the field (— no company — until one is chosen) and type a few letters: it lists only real notes of the type it points at — never a template, nothing in .atlas, nothing archived. A name that starts with what you typed comes first, then one with a word that does, then one with those letters in order (lkpr finds Larkspur Payroll, from three letters). Case and accents don't matter: zoe finds Zoë. A note's aliases count too, and the list says which alias matched. Among equal matches, the notes you link most lately and most often come first. Each row shows the note's type in its colour and its folder.
  • ↓ ↑ move, Return picks, Tab picks the highlighted note (never Create, so a typo then Tab makes nothing), Esc takes back what you typed and closes the list. If the notes can't be read, the list says so. Typing in Japanese, Chinese or Korean works: the Return that ends a word picks nothing.
  • Create <type> ‘…’ is offered when no note in the vault is called what you typed — linked already or not, of any type (Create company ‘Larkspur Payroll’). DFAI makes a new note of that type from its template — the template itself is left untouched — and links it. It goes in its type's home folder — a company in Companies/ — numbered if the name is taken.
  • In a text property, type [[ and the same list offers every note; pick one and [[Its name]] goes in where you typed.
  • A name a link couldn't reach — one holding #, ^, [ or ] — is refused, with the reason: “Acme #1” cannot be linked: a link stops at #. So is a name with nothing left once the characters a file name can't hold (/, :, | and the like) are turned to spaces: Give the new company a name. Nothing is made either way.
  • Dates save when you leave the field or press Return. Use Clear to remove one.
Title and file name. Editing the title at the top renames the file, unless the note has a title property, in which case it edits that. Clearing a title that came from the property removes it.
