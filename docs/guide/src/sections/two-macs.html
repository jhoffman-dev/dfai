Set up a second Mac

A checklist for running DFAI on two Macs with one vault: install, open the same synced vault, set what each Mac keeps for itself, decide which Mac runs automations and the meeting import, and check it worked. It assumes the first Mac already syncs the vault.

On the first Mac, before you start

  • Settings (⌘,) → Sync says “Sync set up: this vault now syncs with its GitHub repository.”, and the light at the bottom of the sidebar says Synced. Press Sync now so the second Mac starts from everything.
  • Note whether Run automations on this Mac is on. The Mac that set up sync first has it.

1. Install DFAI on the second Mac

  1. Install the tools, once: xcode-select --install; Homebrew; brew install node@22 pnpm gh; Rust with the rustup installer (curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh, accept the default). The README's Prerequisites has the details.
  2. Log in to GitHub, which sync uses: gh auth login, then gh auth setup-git.
  3. Get DFAI and start it. The first build takes a few minutes.
git clone https://github.com/jhoffman-dev/dfai.git ~/Projects/atlas
cd ~/Projects/atlas
pnpm install
pnpm tauri:dev

2. Open the same vault

  1. On Open a vault, press Open a vault from GitHub… — or, with a vault already open, the vault's name → Open a vault from GitHub….
  2. Paste the vault repository's address from GitHub's Code button (the plain address — one with a token in it is refused).
  3. Choose folder…: somewhere outside the DFAI folder and outside any other git repository, such as ~/Vaults. DFAI copies the vault there and opens it; the search index builds itself.
One way to sync, not two. Don't copy the vault across by hand, or keep it in iCloud Drive or Dropbox as well: two syncs writing the same files make conflicts. GitHub, through DFAI, is the one.

3. Set what each Mac keeps for itself

The vault brings its notes, types, views, templates, automations and the vault's settings (quick add types, your profile, which Google calendar). These stay on each Mac and need doing again:

SecretsSettings → Secrets: Set… each one marked not set on this Mac, with its sites. They live in this Mac's Keychain.

4. Choose the Mac that runs automations and the meeting import

  • One Mac does both. Automations and the meeting import run only on the Mac with Run automations on this Mac on, so two Macs never run the same rule. Connecting the second Mac leaves them where they are. The other Mac's Inbox says how many meetings are waiting for this one, with Process here to move them (see the meeting import).
  • Pick the Mac that is awake most of the day. n8n sends each meeting to the Mac it runs on, and that Mac's DFAI, open with the Local API on, writes it into the vault. The importing Mac files it in the Inbox at its next pull after the file reaches it — within a minute or so if it's the same Mac, otherwise once sync brings it over.
  • It waits for a pull after starting or waking. Even the chosen Mac imports nothing, and runs no Claude rule, until a pull has finished since DFAI started or the Mac last woke, and the settings that pull brought still name it. After a night asleep it catches up as soon as that first pull is done. While Pause sync on this Mac is on, it waits; Settings → Sync says so.
  • To move them, turn on Run automations on this Mac in Settings → Sync on the Mac you want. Until the other Mac next syncs and reads that, both may import a meeting; they come to the same answer for every file, and sync keeps both if they write the same one. A Mac that was asleep when you moved them reads it at its first pull after waking, before it imports anything.

5. Check it on the second Mac

  1. The light says Synced, and the sidebar shows the same notes, types and views as the first Mac.
  2. Press ⇧⌘D: today's note opens — the same one the first Mac made today, once it has synced; made here otherwise.
  3. From another app, press ⌃⌥N, type a line and press Return: it's in the Inbox here, and on the first Mac within a couple of minutes.
  4. Edit a note on the first Mac; it appears here within about a minute, or at once with Sync now.
  5. Settings → Sync on each Mac: Run automations on this Mac is on on exactly one of them.
  6. The light never says Sync failed or N conflicts; if it does, click it — Settings → Sync says what happened.
