DFAI on the web and iPad

DFAI also runs in a browser, at app.dailyflowai.com, so an iPad can work in the same vault as a Mac. It reads and writes the vault's GitHub repository itself: no server in between keeps your notes, and the Mac and the iPad meet in that repository.

Start

  1. On the Mac, sync the vault with a GitHub repository first — see Sync between Macs. The iPad works in that repository, so it needs one.
  2. Install the DFAI GitHub App on that repository alone, then press Sign in with GitHub — see Signing in on the web. DFAI opens the repository you gave it; there is nothing else to pick.
  3. The first time, DFAI builds its search index in the browser, which takes a moment on a big vault. After that it reads again only the notes that changed.

Put it on the Home Screen

  1. Open app.dailyflowai.com in Safari on the iPad, press Share, then Add to Home Screen.
  2. DFAI now opens from its icon, full screen like an app, and it opens even with no connection.
  3. When a newer DFAI is out, a bar says Update ready. Press Reload when you are ready to use it.

With no connection

  • Notes you have opened before open again. The browser keeps the notes you use, up to about 50 MB, letting the longest-unused go first. A note you have never opened says “This note is not on this device yet; it needs a connection”.
  • Typing still saves. A save that cannot reach GitHub waits on the iPad, and the note says Not saved yet. When the connection is back, the waiting saves go to GitHub in the order you made them, and the words go away.
  • Signing out asks first while any save is still waiting, because signing out deletes waiting saves from the iPad for good.

When the Mac changed the same note

  • On the web every save is a commit to GitHub. If the note changed there since you opened it — Mara's Mac synced an edit to Plan, say — GitHub refuses the save, and DFAI never writes over the other version.
  • The note shows a bar with two choices. Keep mine as a copy saves your text beside the note as Plan (conflict from DFAI web).md and leaves the newer version as it is. Discard my changes lets your edit go and shows the newer version.
  • There is no Overwrite on the web: it would replace, unseen, what the Mac wrote. Keeping a copy loses nothing — read both, keep what you want, and delete the copy.
  • The Mac names the copies it makes of an iPad edit the same way, so a copy from either side says conflict from DFAI web. A note deleted elsewhere while you were editing it is put back, since an edit never loses to a delete.

Export and links

  • Export… downloads the note as Markdown: its .md file, or a .zip when it has pictures or you chose several notes — see Exporting notes.
  • A web link in a note opens in a new tab.

What the web can't do

These need the desktop app. Everything else works on the web, in the same vault. Settings → Not available here shows the same list, and this one is made from the same place when the guide is built, so the two agree.
