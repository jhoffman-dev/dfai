Links and the graph

  • Click a link to peek the note it names, over the page you are reading. ⌘-click opens it in a new tab and ⌘⇧-click beside; a link to a heading or a block opens its note there. Rest the pointer on a link for a moment to see its card.
  • Link a note by typing [[ and the start of its name — the list ranks notes as a link field does (see Properties); if no note is called what you typed, Create ‘…’ writes the link and makes the note beside the one you're in, as Obsidian would. A name with /, | or # is never offered, and one a file can't hold is cleaned — [[Q3: plan makes Q3 plan and links [[Q3 plan]]. ⌘Z takes the link back out but leaves the note it made; delete that like any note. Link a heading or block with [[Note# (see Blocks and embeds), a person by typing @ (see People and mentions), with / → Link to note, or … → Link to…. Any link to a note can also show as a card — see Bookmarks.
  • The Links panel at the foot of a note shows links in and out, including relations like a task's project; on a person's page, the links in are headed Mentioned in. Unlinked mentions finds notes that name this one in plain text; Link turns the mention into a link.
  • Graph (under Search) draws notes as dots coloured by type, sized by how connected they are; relations are dashed. Pan, zoom, drag; click to open, ⌘-click to open beside.
  • … → Show in graph centres it on one note, one or two steps out. Filter by type, hide unlinked notes, or switch to List for the keyboard.
  • Archived notes aren't drawn, and links from them don't count, until you turn on the graph's Archived switch.
