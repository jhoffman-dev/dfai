SQL queries

The other option on the Query page: read-only SQL over the index. Each type is a table named v_<type>, holding each note as a query's cells do: a note whose type is written in capitals is a row, a status written as a list is blank, and a date written as two days is the first of them.

SELECT title, status, phase
FROM v_task
WHERE status IS NOT 'done'
ORDER BY phase
  • Open New query and choose SQL beside DFAI query.
  • ⌘ Return runs it. The list on the right shows every table and column; click one to insert it.
  • Save as view keeps it in the sidebar. Add to dashboard turns it into a widget (table, number or bar chart).

Queries can only read. Anything that would change the index is refused.
