Dashboards

A strip of single figures over a grid of panels: numbers, a hero, bar charts, donuts, lines, rankings, lists, tables, SQL and DFAI queries.

What it shows

  • The strip. Number widgets and the hero sit in one row across the top, each a label over a figure, some with a short figure beside it (4 phases, 67%). A zero still shows (In flight 0).
  • The hero is three cells on the strip: the total under the widget's title, with how many groups it spans (4 phases); the finished part (Done) with its share (67%) and a thin status bar of the whole; and the current group with its count (Current phase: Phase 14, 3 tasks).
  • Panels. Every other widget is a panel under a plain heading, divided from the next by a hairline.
  • Bar charts are grey with the current group in blue, marked by a Current phase key beside the heading. The value is written over the tallest bar and the current one; hover any bar for its group and count (Phase 11 · 3 tasks).
  • Show as table. The table button on a bar chart swaps it for a table of the same numbers — group, count and share — with the current group's row marked. Press it again for the chart. It isn't saved: the chart comes back the next time the dashboard opens.
  • Donuts are drawn as one stacked bar over a table of the groups. Grouped by status, each part and its row's dot is that status's colour — a GTD status too, so Done is green as it is everywhere; anything else takes a shade of its own.
  • Rankings list the top groups with a bar each and the current one in blue; the heading says how many are shown (5 of 6 tasks). Lists give each note one row, with its other values on one line (P14 · 1h).
  • A chart with nothing to count says Nothing to chart yet.

Make and arrange one

  1. Make one with the + beside the vault's name (New note) → the Dashboard template. It lands in Dashboards.
  2. Press Customize. Use Add widget, or … → Edit widget on an existing one.
  3. In the side panel choose the kind, the type, what to group by and any filters. The preview updates as you go.
  4. Drag the grip to move a widget; drag its right edge to make it wider or narrower. ⌘Z undoes. Press Done when finished.

From the keyboard: focus a grip, Space to pick it up, arrows to move, ⇧+arrows to resize, Space to drop, Esc to cancel.

To put a query across types on a dashboard, build it on the Query page and press Add to dashboard there — see Queries. The widget lists its notes in their groups and sub-groups, each group folding on its own.
