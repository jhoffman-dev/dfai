Claude artifacts

Keep the pages, decks and designs Claude makes, organised by project and kind, readable offline.

Three ways to save one

Paste a link

New menu → Claude artifact…, or paste a claude.ai artifact link into search. Only the link is kept; DFAI can't sign in to claude.ai.

Drop the file

Drop an .html file (or pick a folder) in that dialog or on an artifact note, to keep a copy that works offline.

Ask Claude

A Claude session connected to DFAI can call atlas_save_artifact and save the link and the copy in one step.

Browse

The Artifacts view is a gallery grouped by kind — page, deck, design, doc — with project, tags and a thumbnail of each.

An artifact note shows its saved copy below its properties, in a sealed frame that can't reach the app or your vault, with Open link, Full screen, Reload and Regenerate thumbnail.

Thumbnails

  • When an artifact gets a saved copy, DFAI takes a picture of it by itself and uses it on the artifact's gallery card. The picture is kept with the copy.
  • For artifacts saved before this, or any without a picture, press Generate missing thumbnails in the Artifacts view's toolbar. It counts down as it works (Generating thumbnails… 3 left) and then says how many it made.
  • On one artifact, the Thumbnail row has Regenerate and Clear. A link with no saved copy can't be pictured — only a copy can.
