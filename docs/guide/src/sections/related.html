Related notes and trails

For walking a line of thought across notes, Zettelkasten-style: notes close in meaning that you haven't linked yet, and a trail you step along and keep.

Related notes

  • Related notes sits under the Links panel at the foot of a note. Open it and it lists the notes closest in meaning to this one that aren't linked to it either way — not by a link in either note, and not by a relation like a task's project. The note itself, archived notes and templates are never listed.
  • It is found by meaning, so it needs By meaning turned on in ⌘K on this Mac once. Until then it says so. While DFAI is still reading the vault for meaning it says how far it has got (12 of 40 notes), and fills in once it has read this note.
  • It looks only while it is open, and only once the note is drawn, so opening a note never waits on it. Leave it open and the next note opens with it open too.
  • Link writes a real [[link]] into this note, under a Related heading at the end — ## Related, then - [[Garden]], added to the list if the heading is already there. Nothing else in the file changes — except that a note ending inside an unfinished code block has the block closed first, so the link reads as a link. A suggestion is never a link until you choose Link.
  • Dismiss hides a suggestion for this note. Dismissals are kept on this Mac, not in the vault, so the other Mac may offer it again.

Trails

  • Walk a trail from here, in Related notes, starts a trail on this note. A band over the note shows the path so far — Payroll ideas → Budget → Mara Quill — with the notes you can step to next: Linked (links either way) and Related (close in meaning).
  • Pick one to step to it; it opens in the same tab. Step back and Step forward walk the path, and a step's name goes straight to it. Stepping somewhere new from an earlier step branches: the steps after it are dropped, as a browser's Forward is.
  • Open a note some other way and the band goes; step back onto the trail and it comes back. End trail drops it.
  • Save trail writes an ordinary note beside the first step, Trail from Payroll ideas, numbered if the name is taken: one link a line, in the order walked — 1. [[Payroll ideas]], 2. [[Budget]], 3. [[Mara Quill]]. Edit it like any note; the graph and backlinks see every step. A step deleted or renamed since you walked it is left out, and the band says how many were.
  • Claude can read related notes too, through the atlas_related tool — never turning By meaning on, and never writing a link itself.
