⌘NNew note
⇧⌘NQuick capture a task
⌃⌥NQuick capture from any app — DFAI comes forward with capture open (change it in Settings)
⌥⌘NOpen capture (as ⇧⌘N, but not over a palette, a dialog or the peek)
⌥↑ ⌥↓Move a sidebar section up or down, while its grip is focused
⇧⌘DToday's note
⌘JOpen Ask; on Ask, go back to where you were
⇧⌘JOpen or close Claude in the right sidebar
⌥⌘\Show or hide the right sidebar
⌘SSave now
⌘[ ⌘]Back, Forward, in the tab you're in
⌘T · ⌘W · ⌘⇧TNew tab · close the tab (never the window) · bring back the tab closed last — see Tabs
⌃Tab ⌃⇧Tab · ⌘1…⌘9Next, previous tab · a tab by its place (⌘9 the last)
N W S D (or X) · T PInbox, on a focused task row: Next, Waiting, Someday, Done · Defer date, project — see PARA and the Inbox
X · T · D · N W S · MToday, on a focused row: done · choose for today · defer a day · Next, Waiting, Someday · Move to… — see Today
J K · Return · UInbox and Today, on a focused row: next, previous row · open the note · undo the last change (⌘Z too)
⌘\Show or hide the sidebar
⇧⌘\Split the window, or close the pane you're in (also the split button and each pane's ×)

⌘D · ⇧⌘↑ ⇧⌘↓ · ⇧⌘⌫Duplicate · move up, down · delete the block the caret is in

Return · ⌘ ReturnOn a selected bookmark: start a new line after it · open its note
@ and a letterMention a person, while writing; Return picks a person, never Create person — ↓ to it first
# and a letterTag suggestions, while writing; ↓ ↑ to choose, Return or Tab to write it
⌘ ReturnRun a query now — SQL, or a DFAI query as text (in an automation's Which notes, check it now)
M W 3 D ACalendar: month, week, 3 days, day, agenda (with the calendar focused)

⌘ZUndo a dashboard change, while customizing
EscThe peek: close it, from the text too; the focus goes back to the row or link that opened it

⌥↑ ⌥↓The peek: previous or next row from anywhere in it, the text too
