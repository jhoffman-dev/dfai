Blocks and embeds

Link to one paragraph, list item, task or heading of a note, or show it inside another note, live. DFAI writes these the way Obsidian does, so they work in both.

Link a block

  • Type ![[ and pick a note. Its headings and blocks are offered next, each with a line of preview and its kind (Heading 2, Text, List item, Task, Quote, Callout, Code, Table); typing narrows them. [[Note# does the same for a plain link.
  • Picking writes ![[Note#^id]] for a block or ![[Note#Heading]] for a heading.
  • If the block has no id yet, DFAI adds one (six letters and digits) to its note and changes nothing else there. While that note has unsaved typing it refuses with The note has unsaved changes. Save it, then pick again.

The embed

  • ![[Note#^id]] or ![[Note#Heading]] alone on its line shows that block, live and read-only, under its note's name. Change the source and the embed follows.
  • Click the name (Open the block where it is written) to open the note at the block, briefly highlighted. A [[Note#^id]] link does the same.
  • A missing note shows No note is called “X” — it may have been renamed or deleted. A missing block, “Note” has no block ^id — it may have been deleted., or “Note” has no heading “H” any more. One that can't be read, This block could not be read just now.
  • A block from an archived note still shows, with an Archived chip.
  • One level deep: an embed inside a shown block is shown as a link. A note can embed its own blocks too.
  • ![[file.pdf#…]] and other embeds of things that aren't notes stay links.

Block ids

  • Obsidian's ^id, at the end of a paragraph, list item, task or heading, or on its own line after a table, quote, callout or code block. DFAI shows it as a faint ^id after the words.
  • An id follows its block through edits, and when the block becomes a list item, task, quote or heading.
  • A note that already has the same id twice keeps both; when you pick one of them, it gets a new id of its own so the link opens the block you chose.
  • Renaming the source note keeps #^id and #Heading on every link to it.
