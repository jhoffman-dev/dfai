Switch features off

Settings (⌘,) → Features, just under Profile: one row for each key feature, with a switch and a line saying what it is. Switch off what you don't use and it leaves the view.

  • Reading — PDFs and EPUBs in the reader, the Library and All highlights. Switched off, the sidebar's Library and All highlights rows go, and so do Add PDF…, Add EPUB…, Library and All highlights in ⌘K. A literature note's highlights stop offering Open in PDF and Open in EPUB. DFAI doesn't load the reader's code either, so it starts no slower for having it.
  • Kindle — Kindle highlights synced into literature notes. It needs Reading: with Reading off, Kindle's row says Needs Reading. and its switch can't be flipped until Reading is back on. Switched off, Settings → Kindle and ⌘K's Connect Kindle, Sync Kindle now and Disconnect Kindle go, and the four-hourly sync stops; a sync already running finishes quietly, since it writes whole notes. Switch it on and it runs its usual sync straight away, no restart needed. With Kindle off you can't reach Disconnect, so your Kindle sign-in stays on this Mac: switch Kindle on to disconnect.
  • Ask and Claude chat — Switched off, the sidebar's Ask, ⌘J, ⇧⌘J, the page bar's Claude button and the right sidebar's Claude tab go, and a tab on Ask shows Ask and Claude chat is turned off. Claude still works elsewhere: the Inbox's Suggest, Skills' Ask Claude… and rules with a Claude step carry on, so Settings → Claude stays. Search by meaning has its own switch and isn't touched.
  • Graph — Switched off, the sidebar's Graph and a note's Show in graph go, and a graph tab shows Graph is turned off. Backlinks and related notes stay.
  • Slack capture — Switched off, a pasted Slack link stays a plain link: no preview and no Save as task. Settings → Slack goes too. Your Slack token stays in the Keychain for when you switch it back on.
  • Nothing is deleted. Your PDFs, EPUBs and literature notes stay where they are, and open tabs stay open. A tab on a PDF, a PDF clicked in Pages, a highlight's link or a search result that would open the reader shows Reading is turned off instead (and a tab on Ask or the graph says the same for its feature), with Turn on in Settings, which opens Settings at Features. Switch it back on and the reader is there again, in the same tab.
  • The choice is the vault's. It's kept in this vault's settings (.atlas/settings.md, as featuresOff), so every Mac that syncs it, and the web, shows the same features. Everything is on until you switch something off, and a feature added in a later version arrives on.
  • Claude still answers. The local API and the MCP tools keep working for a feature that's off: the switch is about what you see, not what your tools may do.
