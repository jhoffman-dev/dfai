Switch features off

Settings (⌘,) → Features, just under Profile: one row for each key feature, with a switch and a line saying what it is. Switch off what you don't use and it leaves the view.

  • Reading — PDFs and EPUBs in the reader, the Library and All highlights. Switched off, the sidebar's Library and All highlights rows go, and so do Add PDF…, Add EPUB…, Library and All highlights in ⌘K. DFAI doesn't load the reader's code either, so it starts no slower for having it.
  • Nothing is deleted. Your PDFs, EPUBs and literature notes stay where they are, and open tabs stay open. A tab on a PDF, a PDF clicked in Pages, a highlight's link or a search result that would open the reader shows Reading is turned off instead, with Turn on in Settings, which opens Settings at Features. Switch it back on and the reader is there again, in the same tab.
  • The choice is the vault's. It's kept in this vault's settings (.atlas/settings.md, as featuresOff), so every Mac that syncs it, and the web, shows the same features. Everything is on until you switch something off, and a feature added in a later version arrives on.
  • Claude still answers. The local API and the MCP tools keep working for a feature that's off: the switch is about what you see, not what your tools may do.
Only Reading has a switch so far. Kindle, Ask and Claude chat, Automations, Meetings, Slack capture and Graph get theirs next.
