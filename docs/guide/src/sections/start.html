Start the app

DFAI runs from its project folder in development mode, which reloads screen changes by itself.

cd ~/Projects/atlas
pnpm tauri:dev

When to restart

  • Screen changes appear live while pnpm tauri:dev is running.
  • Changes to the Rust side (new commands, the index): stop with Ctrl C and run pnpm tauri:dev again. The first rebuild takes a minute or two.
  • New packages: stop, run pnpm install, then pnpm tauri:dev.

The first time, choose your vault folder. DFAI remembers it and reopens it next time. The search index rebuilds itself when it needs to.

Used it when it was called Atlas? The first time DFAI opens on a Mac that ran Atlas, it copies what Atlas kept on that Mac: the vault it had open, the API's token, your secrets, this Mac's sync name and your settings. macOS may ask once for each secret — choose Always Allow. A secret it can't read is asked for again on the next two launches; after that DFAI says which, so you can set it again in Settings → Secrets. Atlas's own copy is left as it was. If Atlas is still open, DFAI asks you to quit it first; if something can't be copied, DFAI says why and doesn't open, and the next launch tries again.
