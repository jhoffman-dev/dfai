Your files

  • Every note, type, view and dashboard is a markdown file in your vault. DFAI writes back only what you changed; everything else keeps its exact bytes, so Obsidian and git see clean edits.
  • Links are stored as [[Name]], the same way Obsidian writes them. A bookmark is the same link alone on its line followed by <!-- atlas:bookmark -->, a comment Obsidian's reading view and GitHub hide; nothing else about the card is stored.
  • A block link or embed is [[Note#^id]] or ![[Note#^id]], with the ^id written after its block, as Obsidian writes it — see Blocks and embeds. A - [ ] line with nothing after it is an empty task.
  • Tags are stored as you typed them, #tag in the text or a tags: list in the frontmatter. Obsidian reads single-word and nested tags the same way; it reads #tag me# as #tag followed by text.
  • Archived notes are ordinary files in Archive/, at the path they had, with archived and archivedFrom in their frontmatter, so Obsidian still opens them.
  • Frontmatter written flow-style, {status: done, tags: [a]}, and files that start with a byte-order mark are kept intact when DFAI changes a property.
  • .atlas/ holds types, templates, views, dashboards, sources, automations and settings. It shows as System in Pages — all but the templates and the skills, which are on the Templates and Skills pages, and the views and dashboards, which have their sections.
  • A template is a plain markdown file in .atlas/templates/, named for what it makes: Person.md, Daily.md, Task.md, Artifact.md.
  • Each automation is a note in .atlas/automations/, and its run log a note in .atlas/automations/log/, named after the rule's id. Both are plain markdown you can read, diff and edit.
  • The Activity log is not in the vault: one file per vault in DFAI's data folder on this Mac, about 30 days or 5 MB.
  • A link (symlink) in your vault that points into .atlas or .git doesn't open — DFAI refuses it, so nothing can reach DFAI's own files by a side door.
  • The search index lives in .atlas-cache/. It's only a copy; if it's ever wrong, Settings → Index → Rebuild.
  • Pictures you add go in attachments/ (or beside the note, if you chose that in Settings → Images). Thumbnails DFAI makes of pages live in .atlas-cache/thumbnails; an artifact's is kept with its saved copy.
  • Each chat with Claude is a note in Chats/, written once and then only added to. Claude's proposed changes are written only when you press Accept, never into .atlas, a hidden folder or Chats/.
  • Proposals wait as notes in Inbox/Proposals/; answered ones move to Archive/Inbox/Proposals/ with their state.
  • A synced vault is a git repository; DFAI keeps its own lines in .gitignore (the index, Finder and Obsidian per-Mac files). See Sync between Macs.
  • Secrets live in the macOS Keychain, never in the vault. The chat's settings (which way to reach Claude, the model) are kept on this Mac; your name is in the vault's settings, so it syncs.
  • Nothing leaves your Mac unless you turn on the Local API, connect a source, turn on sync (the vault goes to your GitHub repository), or ask Claude in the chat — then what you ask, the page on the chip and what Claude reads go to Anthropic, through Claude Code or your API key.
