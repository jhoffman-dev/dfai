Pictures in notes

Put a picture anywhere in a note. DFAI copies it into your vault and writes an ordinary markdown image, so Obsidian shows it too.

Paste

A screenshot or a copied image file: ⌘V in the note.

Drop

Drag image files from Finder onto the note. They land where you drop them.

Block menu

Type / → Image and pick a file. It goes where you typed.

Page menu

… in the top bar → Insert image…

  • While a picture is saving, a placeholder holds its place. If it can't be saved, the reason shows there and nothing is added to the note.
  • See it larger: click a picture and it opens over the note, as large as the window holds it — in a note you're editing, in the feed, in a note read in a panel, and in a block shown from another note. Zoom with ⌘+ and ⌘−, a pinch or ⌘-scroll, or the − / + buttons; ⌘0 or Fit shows all of it again, and a double-click goes between fit and its real size. Drag to move around a zoomed picture. ← and → go to the note's other pictures. Esc, × or a click beside the picture closes it. A picture that can't be read says so there.
  • Resize it on the page: hover a picture and drag the handle on either side. It can't get wider than the column or narrower than a thumbnail. The width is saved the way Obsidian writes it, ![Q3 chart|400](chart.png), and nothing else in the line changes; in a table it's \|400, as a table needs. A double-click on a handle puts it back to its own size. ⌘Z undoes a resize, and letting go where you started changes nothing.
  • Alt text: after closing the larger view the picture stays selected; type its alt text (a short description) in the Describe the image field under it. Return or Esc goes back to writing. Alt text that ends like a size, such as Route 66|2024, is saved as Route 66\|2024 so it stays words.
  • Room to type: with a picture selected, Return goes on after it — a new line, or in a list a new item — and never removes the picture. A note that ends with a picture keeps an empty line under it to type on: ↓ on the picture goes there, or click it. ↑ on a picture at the very top makes a line above it.
  • PNG, JPEG, GIF, WebP and SVG work, and HEIC when the Mac can draw it. Each can be up to 20 MB. Two pictures with the same name are numbered, never overwritten.
  • Deleting a picture from the note removes it from the note only. The file stays in the vault.
  • Moving a note: Update N links fixes its pictures' paths too.

Where they go: Settings (⌘,) → Images → Images go in: the Attachments folder (attachments/, the default) or Beside the note, in the note's own folder.
